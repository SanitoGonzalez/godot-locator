# Website Structure

Docs live **outside** the website folder at `../docs/<section>/`. Each navbar tab maps to its own plugin in `docusaurus.config.ts`. Sidebars are fully autogenerated from the filesystem.

## Adding a top-level tab

1. Create `../docs/<name>/introduction.md` with `slug: /` and `sidebar_position: 1`.
2. Add a plugin entry in `docusaurus.config.ts`:
   ```ts
   ['@docusaurus/plugin-content-docs', { id: '<name>', path: '../docs/<name>', routeBasePath: '<name>', sidebarPath: './sidebars.ts' }]
   ```
3. Add a navbar item:
   ```ts
   { type: 'docSidebar', sidebarId: 'sidebar', docsPluginId: '<name>', position: 'left', label: '<Label>' }
   ```

## Adding a sidebar category (subtab)

Create a subdirectory inside the section with a `_category_.json`:
```json
{ "label": "Category Name", "position": 4, "collapsed": false }
```

Add pages inside it — each with `sidebar_position` frontmatter.

## Verifying changes

```sh
cd website && bun run build
```
