# Godot Locator CLI

A command-line interface for godot game runtime automation designed for coding agents. Token-efficient commands and installable skills let agents balance godot game runtime automation with large codebases and reasoning within limited context windows.

## Example

```sh
godot-locator-cli

```

## Key Features

- **Token-efficient** — concise CLI output avoids loading large tool schemas into the model context
- **Skill-based** — concise CLI output avoids loading large tool schemas into the model context
- **Ref-based** — accessibility snapshots with element refs for deterministic interaction
